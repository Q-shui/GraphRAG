# 05 数据版本与统计口径规范（P1-D）

## 范围与证据等级

- **代码事实**：本规范对应 `p1-daily-extract-v1`；完整可机读清单在 `manifests/p1_daily_extract_v1_manifest.json`。
- **代码事实**：只使用派生抽取的 `cell_id`、`record_date`、`average_voltage`、`working_voltage`，并保留 `source_file`、`source_row`。抽取为只读，不修改 21 个原始 XLS。
- **推断**：数值字段的单位、聚合窗口、生成时刻和业务物理含义尚未被数据字典确认。因此所有答案的单位为 `unknown`，不得表述为工程阈值、因果关系或性能结论。

## 版本与可复现性

版本清单记录每个源文件路径、SHA-256、大小、脚本 SHA-256、Python/OS、21 个槽号、30,691 条派生行及六列模式。重新构建命令：

```powershell
$py='C:\Users\23389\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe'
& $py .\aluminum_industry_qa_benchmark\P1_semantic_calibration\scripts\build_p1_prototype.py
```

日期解析为首 10 个字符，`/` 归一为 `-`，再按 ISO 日历日期解析。所有日期窗为闭区间 `[start_date, end_date]`。

## 统计与异常口径

| 项目 | 可执行口径 |
|---|---|
| 允许字段 | `average_voltage`、`working_voltage`；映射自已校准的“平均电压”“工作电压” |
| 空值 | 保留记录；数值统计排除空值，输出 `valid_record_count` 与 `missing_record_count` |
| 均值 / SD | 算术均值；总体标准差（除以有效样本数） |
| 重复 | 原始行不删除。gold 统计用 `deduplicated_exact`：按 `(cell_id,date,average_voltage,working_voltage)` 完全相同去重，保留按 `(source_file,source_row)` 排序后的首条 |
| 冲突 | 同一槽号/日期去重后仍有不同数值对，返回 `E_CONFLICTING_RECORDS`，不产出统计答案 |
| 无记录 / 无有效值 | 分别返回 `E_NO_RECORDS` / `E_NO_VALID_VALUES` |
| 日期缺口 | 输出 `calendar_days`、`observed_days` 和 `gap_warning`；不插补 |
| 数值容差 | gold 浮点比较绝对误差不超过 `1e-6` |

**代码事实**：当前派生抽取有 30,691 行、63 条上述六列口径的完全重复行、平均电压缺失 0 条、工作电压缺失 162 条。该重复判定不能取代 P0 对 12 个字段的完整行审计。

## 边界

这是通用 CSV 回顾性检索/统计原型，不是电解铝工业知识问答的充分实现。字段 B 级仅允许描述性输出；数据字段 C 级不进入 gold。
