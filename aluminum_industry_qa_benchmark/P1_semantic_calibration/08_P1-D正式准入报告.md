# 08 P1-D 正式准入报告

## 结论：CONDITIONAL GO（限“可验证回顾性数据问答最小原型”）

**代码事实**：7 条题均具版本、字段限制、答案、容差、reference path 与独立重算；回归、边界、空值、重复、冲突和类型错误均已覆盖并通过。

**推断**：该成果证明“从带溯源 CSV 做封闭字段检索/描述统计”的最小链路可行；它尚不能证明工业领域知识问答、运行诊断或 Agent 能力。

| 准入项 | 判定 | 条件 |
|---|---|---|
| A. 数据版本与溯源 | GO | 21 XLS、派生 CSV、脚本均有 SHA-256 |
| B. 基础 QA 计算 | GO | 仅两数值字段，闭区间、空值/重复/冲突明确 |
| C. 工业语义 QA | NO-GO | 单位、聚合、可用时刻、物理含义未确认 |
| D. 复杂比较/质量告警 | CONDITIONAL GO | 仅描述性比较；严禁性能与因果推断 |

P2 的前置条件：取得字段数据字典/单位/生成规则、核实缺失 5 份日报的清单差异、建立时间可用性与回填说明、人工确认冲突处理业务规则。任何新增“异常/控制/效应”类题，在证据未闭环前均不得进入 gold。
