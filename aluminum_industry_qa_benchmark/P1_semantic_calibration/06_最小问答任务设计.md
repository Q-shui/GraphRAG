# 06 最小问答任务设计（P1-D）

## Gold 范围

**代码事实**：`dataset_prototype/p1_qa_prototype.jsonl` 含 7 条可执行原型题，覆盖 T1–T5。每行含题目、版本、筛选、reference tool call、答案、容差、有效记录数、质量告警和核验状态。

| 类型 | 题号 | 允许回答 |
|---|---|---|
| T1 记录查询 | P1Q001 | 一条带 `source_file/source_row` 的原始派生记录 |
| T2 统计 | P1Q002–003 | 均值、总体 SD、极值、有效/缺失数、覆盖信息 |
| T3 窗口比较 | P1Q004 | 两窗口描述统计与“后减前”均值差 |
| T4 跨槽比较 | P1Q005 | 两槽的描述统计与数值差；禁止绩效解释 |
| T5 数据质量 | P1Q006–007 | 重复、缺失、日期覆盖/缺口告警 |

## 工具契约

| 工具 | 必要参数 | 返回 | 主要错误 |
|---|---|---|---|
| `get_record` | cell_id, record_date, field | 值及原始行溯源 | `E_NO_RECORDS`, `E_CONFLICTING_RECORDS` |
| `calculate_statistics` | cell_id, start_date, end_date, field | mean、population_sd、n、缺失/重复/缺口 | `E_INVALID_BOUNDS`, `E_NO_VALID_VALUES` |
| `compare_time_windows` | cell_id, field, first, second | 两个统计对象与均值差 | 继承统计错误 |
| `compare_cells` | cell_a, cell_b, start_date, end_date, field | 两统计对象与 B-A 差 | 继承统计错误 |
| `inspect_data_quality` | 可选 cell_id / 完整日期窗 | 行数、重复、缺失、槽号 | `E_INVALID_TYPE`, `E_INVALID_BOUNDS` |

实现位于 `scripts/qa_reference_calculator.py`。所有工具输出 `dataset_version` 和 `unit: unknown`；输入类型、字段白名单、日期界限均验证。reference path 是可执行的一种路径，并不声称是唯一合理实现。
