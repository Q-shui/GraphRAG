# P1-A：12 字段语义校准

## 结论

仅“槽号”达到 **A**（直接标识）；“时间、平均电压、工作电压”达到 **B**（日报表头与全量数据结构强支持，但单位、日聚合窗口与可用时点没有厂方定义）；其余 8 个生产字段均为 **C**。C 级字段不得支持机理解释、事件标签或在线预测金标准。

| 字段 | P1 结果 | 影响 |
|---|---|---|
| 槽号 | A；21 个数值 ID，2726—2836 | 可安全用作筛选与分组，不可推断槽型。 |
| 时间 | B；日报日期列无缺失 | 允许回顾性日期过滤；禁止据此宣称日内物理时间或可用时点。 |
| 平均电压、工作电压 | B；数值日报记录，缺失分别 75、162 | 可做原始回顾性检索与描述统计；不能声称瞬时值、单位或在线可得。 |
| 设置电压、氟化铝料量、效应时间、效应电压、噪声 | C | 只能保存原样并报告数值/空缺，不能解释为实际控制执行或工艺机理。 |
| 设定NB、出铝指示量、效应状态 | C | 含义/代码本缺失；尤其禁止把“指示量”当实际出铝量，或把“状态”当已确认阳极效应事件。 |

## 复核数据事实

21 份日报共 30,691 行。字段 profile 见 `source_daily_field_profile.json`。值域是数据观测范围，不是安全区间或工艺阈值。P0 的“63 条完全重复”仍成立；本阶段未删除、插值或修订原始记录。

## 厂方确认单（最小集）

1. 平均/工作/设置/效应电压的单位、采样频率、日报统计窗口、是否为平均/末值、导出延迟与回填规则；
2. 氟化铝料量是计划、下达、称量、实际投加还是日累计量，及单位；
3. 效应时间、效应电压和效应状态的状态机/代码表、清零和累计规则；
4. 设定NB 的全称、单位及算法；
5. 出铝指示量与实际出铝质量、计划值和统计窗口的关系；
6. 噪声的传感器/算法、单位及采样窗口；
7. 是否允许事后人工补录或修改日报。

在以上问题未确认前，P1-C 不应设计涉及事件、异常、控制或预测可用时点的金标准题。
