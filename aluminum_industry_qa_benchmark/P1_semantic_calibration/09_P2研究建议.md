# 09 P2 研究建议

1. **先补证据（GO 前置）**：向数据提供方索取字段字典、单位、日表聚合口径、生成/可用时间、修订规则和 26 vs 21 文件差异说明；每项落到可定位证据。
2. **再扩数据契约**：把 B 级字段逐项升级或降级；为每个 gold 字段写入语义证据、缺失/冲突策略和不可作答边界。
3. **构建分层 benchmark**：保持本版封闭数值题为回归集；新增知识题必须有教材页码/OCR 或人工核准的证据片段，数据题按时间可用性做严格切分。
4. **P2 准入验收**：字段定义 100% 可追溯；每类题有独立 verifier；训练/验证/最终测试无泄漏；人工双人复核一致性与争议处理流程均留痕。

**本地改造方案**：在满足以上门槛之前，不启动 LLM、RAG、Agent 编排或任何模型训练。本版脚本只能作为确定性 reference tool 保留。
