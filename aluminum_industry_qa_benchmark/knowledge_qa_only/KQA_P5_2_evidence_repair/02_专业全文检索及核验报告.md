# 专业全文检索及核验报告

## 实际结果

1. **SINTEF 2017 阴极拆槽尸检**：可读取出版页摘要。研究对象为完全浸渍、石墨化碳块内衬，停槽前服役 2461 天；报告不均匀阴极磨损、典型 potholes 及小尺度 pitholes。样品在不同位置取芯，使用 X-ray CT、光学和电子显微分析。该页还提供全文句柄链接，但本轮工具未能取得该全文。
2. **SINTEF 2015 部分阳极效应实验**：可读取出版页摘要。双阳极、分隔电解质室、共用阴极的低氧化铝冰晶石熔体实验显示：阳极会随其反应阻力而改变电流承担；该摘要不等价于验证后续数值模型的全部局部机制。
3. **SFU 工业槽氧化铝溶解**：页面未能获取，不能标为全文核验。
4. **CFD 氧化铝团聚论文**：出版商页面 403，不能标为全文核验。

因此，阴极/内衬仅补足了一个具有实测拆槽证据的候选知识来源；本轮不新增机理题。
