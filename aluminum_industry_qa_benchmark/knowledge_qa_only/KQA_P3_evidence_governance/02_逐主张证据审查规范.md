# 逐主张证据审查规范

每个参考答案拆为核心结论、机制、参数关系、条件、假设和限制六类原子主张。每个主张关联 `claim_id`、一至多个 `evidence_id`、适用条件、反证链接和审阅记录。

| 标签 | 判定规则 |
|---|---|
| SUPPORTED | 定位原文直接表达主张，且条件一致。 |
| CONDITIONAL | 原文直接支持，但只在已记录条件下成立。 |
| PARTIALLY_SUPPORTED | 核心方向有证据，但答案含未被直接支持的延伸或缺少限定。 |
| INSUFFICIENT | 未找到足以判断的证据；不等于错误。 |
| CONTRADICTED | 同条件下可信证据明确反驳主张。 |
| CONFLICTED | 可信来源存在未解决矛盾，尚不能合并。 |

来源质量采用“门槛 + 说明”而非总分：可获得原文、可定位、来源身份/版本可识别、直接性、条件匹配、独立复核、冲突状态。任何低项都要写明原因；教材不是普适工程规则的自动证明。

试点记录位于 `datasets/claim_evidence_pilot.jsonl`。K006、K033被标为 `PARTIALLY_SUPPORTED`，展示了为什么题级 `Evidence-Verified` 不能替代逐主张支持标签；该文件不改变 v2 原状态。
