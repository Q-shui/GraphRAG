# P2 MVP 问答能力与难度矩阵

| 题群 | 数量 | 主要能力 | 难度来源 | 是否真正需要电解铝知识 |
|---|---:|---|---|---|
| K1/K2 教材概念与解释 | 9 | 概念理解、证据引用、条件识别 | 术语与限定条件 | 是 |
| K3 参数关系 | 1 | 公式/符号条件理解 | 表观量与真实量区分 | 是 |
| K4 多点推理 | 1 | 多知识点整合 | 同页两项必要信息 | 是，仍待专家审查 |
| K5 条件约束 | 2 | 适用范围判断 | 槽型/公式前提 | 是 |
| K6 证据不足 | 2 | 不确定性与拒答 | 教材概念和数据契约边界 | 是 |
| P1 + D1/D2 | 10 | 查询、统计、字段白名单、参数生成 | 日期/空值/去重 | 主要是通用数据处理 |
| D3/D4 | 3 | 窗口和跨实体比较 | 同一口径、解释限制 | 主要是通用数据处理 |
| D5/D6 | 3 | 质量审计、多步工具执行 | 覆盖、冲突、依赖顺序 | 工具调用，非工艺推理 |
| D7 | 3 | 错误恢复、证据不足拒答 | 无效输入与语义边界 | 边界本身涉及领域数据契约 |

M1–M4 可用作“最少工具调用数”辅助标签：单工具为 M1，D015 可记 M3。局限是工具数不等于参数难度、数据质量风险、专业性或分支恢复复杂度；本 MVP 不以 M 等级替代综合难度。

能力矩阵的结论是：知识轨测试领域概念与条件推理；数据轨主要测试自然语言到确定性工具调用。题目包含电解铝文件名并不自动使后者成为工艺机理推理。
