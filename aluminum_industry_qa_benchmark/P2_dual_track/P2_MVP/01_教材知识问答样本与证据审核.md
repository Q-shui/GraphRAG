# P2-A2 教材知识问答 MVP：样本与证据审核

## 产出与状态

本 MVP 产生 15 条候选题，见 `datasets/knowledge_qa_candidates.jsonl`。每条有唯一题号、题型、答案、解释、知识类别、过程阶段、来源 ID、PDF 页/印刷页、短证据定位、适用条件、所需知识点、难度和不确定性。

**代码事实**：15 条均通过结构检查并标记 `Evidence-Verified`；0 条标记为 `Expert-Approved`。这里的 Evidence-Verified 仅指本轮已人工视觉核查“题目答案确能由所列扫描页支持”，不代表独立工艺专家批准。

| 题型 | 数量 | 示例能力 | gold 状态 |
|---|---:|---|---|
| K1 概念/事实 | 6 | 氧化铝去向、槽体构成、测量项目 | 页级证据已核验，候选 |
| K2 原理解释 | 3 | 溶解影响因素、电阻解析、人工/自动化边界 | 页级证据已核验，候选 |
| K3 参数关系 | 1 | 表观槽电阻采样公式 | 页级证据已核验，候选 |
| K4 多知识点推理 | 1 | 定时下料模式中的异常分支 | 页级证据已核验，候选，需术语审阅 |
| K5 条件约束 | 2 | 槽型泛化限制、表观/真实电阻条件 | 页级证据已核验，候选 |
| K6 证据不足/拒答 | 2 | 不能用电压升高判定事件；不能由“日报”推出全天均值 | 答案为“不可确定”的证据边界 |

## 来源与核查方式

**教材事实**：本轮只使用视觉核查的章节首页或首个实质内容页，来自《现代铝电解》的第 3、6、11、14、21、22、24 章，以及《铝电解生产技术》第 5 章与《铝电解技术问答》第 11 章。每条记录保留 PDF 页与印刷页；渲染图存于 `evidence/pdf_probe/`。

**本地改造方案**：下一轮专家复核应逐题核对术语、限定条件、版本/槽型适用范围，并填写审查表的“人工复核结论”。K006、K013 是边界题，必须同时保留“教材概念证据”和“现场字段未映射”的限制；不能被改写为事件诊断题。

## 专业性与风险评定

| 类别 | 专业知识必要性 | 可由教材直接回答 | 风险/处理 |
|---|---|---|---|
| K001–005 | 是 | 是 | 保留页码与适用对象 |
| K007–010 | 是 | 是 | 公式/控制知识不得投射到日报字段 |
| K011–012、K014 | 是 | 是 | 不把历史/作业描述写成通用操作指令 |
| K015 | 是 | 可从图文模式获得 | 需确认术语译解和控制系统版本 |
| K006、K013 | 是 | 教材 + 数据契约共同支持拒答 | 不可作为“现场异常/日均值”结论 |

多证据题只保留 K015：其答案依赖“效应等待起点”及“停电/人工翻片分支”两项同页信息。其余题按单证据或条件约束题管理，避免把文本长度误写成推理复杂度。

## 当前判断

可以形成**可信的候选专业知识 QA 原型**，但尚不具备正式 gold 的独立专家批准与多版本覆盖。尤其不能用本 MVP 声称已覆盖所有槽型、所有生产阶段或可输出现场处置建议。
