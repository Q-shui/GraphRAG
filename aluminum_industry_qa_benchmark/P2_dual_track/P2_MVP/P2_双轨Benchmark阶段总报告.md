# P2 双轨 Benchmark 阶段总报告

## 已有资产

- 教材轨：15 条 Evidence-Verified 候选，0 条 Expert-Approved；覆盖 K1–K6，页级来源可追溯。
- 数据轨：18 条候选（P1 7 + P2-B2 11）；新增 10 条 Computation-Verified、1 条可验证拒答。
- 工具轨：8 个确定性工具接口，含 schema、查询、筛选、统计、两个比较、质量检查与证据不足拒答；新增题 reference sequences 均实际执行。

## 双轨定位

教材 QA 测试电解铝概念、机理、条件与证据边界；标准答案来自页级教材证据，主要瓶颈是独立专家审核。数据 QA 测试字段受限的检索、统计和工具调用；标准答案来自冻结 CSV 和独立程序复算，主要瓶颈是厂方字段业务语义。两者应作为独立子基准，不能因同属电解铝而强行合成融合 gold。

## 准入结论

可进行**内部探索性**的候选集功能测试：教材侧可考察 RAG 证据定位，数据侧可考察自然语言到工具参数和结果一致性。不可据此发表模型性能排名或 Water-MAS 架构优越性结论。

当前不足以证明 Planning/Execution/Checking 或多智能体的必要性：只有少数多工具任务，缺少 M3/M4 分层、复杂错误恢复、多任务统计能力和公平的单 Agent 对照。下一优先级是独立专家审查、厂方字段直接证据、非重叠评测设计，再考虑模型实验。
